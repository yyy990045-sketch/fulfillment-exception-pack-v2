# 提交材料包

本目录用于整理官方提交前的发行物：

- `solution-pack.md`：可编辑源文档
- `solution-pack.docx`：可编辑 Word 版本
- `solution-pack.pdf`：提交用 PDF 版本
- `demo-fulfillment-exception.mp4`：真实运行演示视频
- `demo-script.md`：视频操作脚本与镜头清单
- `submission-checklist.md`：逐项提交前检查

本地/容器演示入口：`http://127.0.0.1:3410/`。
该入口用于提交前复现，不能替代官方指定平台发布后的 Agent 体验链接。

提交前必须补齐：

1. 官方指定平台发布后的真实 Agent 体验链接；
2. 若设置访问控制，填写体验密码；
3. 真实参赛团队信息和分工表；
4. 再次检查 PDF/DOCX 不超过 50 MB，MP4 不超过 50 MB 且不超过 10 分钟。
