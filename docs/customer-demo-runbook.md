# Customer Demo Runbook

目标时长：15–20 分钟。演示主线是“从管理视图定位风险，进入一条业务线程，完成证据、分析、决策和治理闭环，再切到 Finance 展示底座复用”。

## 1. Operations

- 客户看到：经营摘要、业务上下文组合、异常趋势、治理状态和结果摘要。
- 我要讲：先从管理层视角找风险，再进入具体业务上下文。
- 不要讲：不要把趋势图说成因果结论，不要说所有系统已真实接入。
- 下一步：点击 `SO-MFG-001`。

## 2. SO-MFG-001

- 客户看到：销售订单、履约数字线程、报价、生产、质检、发货、应收、回款、客诉。
- 我要讲：这是同一业务对象上的跨阶段证据链，连接表示业务顺序，不表示因果关系。
- 不要讲：不要说某阶段“导致”了下一阶段异常。
- 下一步：点击“客户收货主张与发货记录不一致”。

## 3. 客户收货主张与发货记录不一致

- 客户看到：96 vs 80，差异 16。
- 我要讲：系统先把冲突变成可核验异常，并保留异常、治理和结果之间的边界。
- 不要讲：不要说哪个数字天然正确，也不要自动认定责任方。
- 下一步：进入 Evidence。

## 4. Evidence

- 客户看到：规则期望、系统记录、客户主张、来源、原文、字段、业务时间和定位。
- 我要讲：每个用于分析的数字都有 Evidence 来源和 locator；没有来源的内容不会进入事实层。
- 不要讲：不要把 Evidence 的存在说成事实已经人工确认。
- 下一步：进入 Analysis。

## 5. Analysis

- 客户看到：已知事实、未知信息、待核实事项、根因假设、支持证据、反驳证据。
- 我要讲：AI 解释是 evidence-grounded 辅助分析，根因只能是待验证假设。
- 不要讲：不要说 AI 已找到真实根因，也不要把假设说成责任结论。
- 下一步：进入 Decision。

## 6. Decision

- 客户看到：推荐动作、为什么、证据依据、人工确认事项、候选方案。
- 我要讲：推荐是治理输入，不是执行结果；人工仍然决定采用哪个方案。
- 不要讲：不要说系统已经自动决定或自动执行。
- 下一步：进入 Governance。

## 7. Governance

- 客户看到：受理、复核、方案、提交审批、审批、执行、回执、结案。
- 我要讲：Review、Proposal、Approval、SoD 和 Execution 是清晰分离的治理步骤；权限和状态由后端决定。
- 不要讲：不要把批准说成业务结果达成，也不要说所有审批角色已完整接入客户 RBAC 后台。
- 下一步：展示回执。

## 8. Receipt

- 客户看到：执行动作、内部回执、时间、来源和状态。
- 我要讲：回执记录系统实际登记了什么，不等于外部真实系统已经完成全部动作。
- 不要讲：不要把内部回执说成 ERP / WMS / QMS / MES 已真实执行。
- 下一步：进入 Outcome。

## 9. Outcome

- 客户看到：基准、当前测量、目标、测量时间和结果状态。
- 我要讲：这是后续业务状态 observation，用来观察是否改善，不做因果归因。
- 不要讲：不要说处置导致改善，也不要展示 ROI 或节省金额。
- 下一步：回到 Operations。

## 10. Operations

- 客户看到：治理状态、异常趋势和结果摘要回到管理层视角。
- 我要讲：同一个底座同时支持业务处理和运营观察。
- 不要讲：不要把 synthetic demo 说成真实客户历史数据。
- 下一步：进入 Solution Pack。

## 11. Solution Pack

- 客户看到：Manufacturing 与 Finance 示例 Pack、绑定业务上下文、规则能力、支持动作和 Generic Workspace。
- 我要讲：核心平台不是写死制造业，Manufacturing 是其中一个 Pack；Finance 使用同一底座。
- 不要讲：不要说当前支持远程插件下载或第三方 Pack 市场。
- 下一步：切换 Demo Organization。

## 12. Finance Reconciliation

- 客户看到：示例财务企业、Finance Context、应收、发票、银行回款、Generic Workspace。
- 我要讲：切换组织后进入同一产品 Shell，展示跨领域复用和 Context 绑定。
- 不要讲：不要说已经接入真实银行、ERP 或客户财务系统。
- 下一步：结束演示，回到当前 Pack 或 Operations。

## Demo Guardrails

- 开始前确认使用 synthetic demo 数据和本地服务。
- 不要展示 API key、tenant UUID、secretRef、连接串或私有客户数据。
- 如果 live provider 未配置，明确说“当前只展示本地 contract / demo 路径”。
- 任何外部系统问题都回答“需要 Connector 实施和联调验证”，不要口头升级为已接入。
