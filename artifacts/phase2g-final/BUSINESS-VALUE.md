# 业务价值

当前前端已经把“订单与货物 → 字段检查 → 真实规划 → 路线/车辆 → 三维货位 → 逐站卸货 → 人工确认 → 导出”串成一条业务路径。

调度员能看到每家门店由哪辆车服务、每件货物的尺寸重量和货位、到店时间、卸货顺序以及冲突原因。路线变化会同步改变车辆归属、货位、卸货步骤和成本，而不是只改变页面文字。

导出的 JSON 是企业数据交接样例，包含场景来源、订单与车辆归属、路线、到店时间、货位、朝向、卸货步骤、已检查约束、边界、费用假设和确认身份。它不是已经完成 ERP/OMS/WMS/TMS 生产集成的承诺。

所有当前数据均标注为合成机制案例。动画是前端播放状态，不是 GPS 或现场遥测；历史三车/两车经营比较和 A/B/C 算法对照分别呈现，不混用口径。
