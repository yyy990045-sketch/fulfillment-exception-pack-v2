# 算法证据

## A/B/C 对照

真实记录：[COMPARISON-ABC.json](../judge-evidence/phase-2f/COMPARISON-ABC.json)。

- A `route-first`：路线先行，再检查固定主布局。
- B `layout-repair`：固定第一次路线，只搜索有限替代布局。
- C `joint-feedback`：布局失败后，在授权范围内尝试替代布局，再尝试路线/车辆反馈。

三种方法使用相同输入、费用、硬约束和 2000ms 预算；三个合成场景各运行 3 次。四店三种方法均可行；九店和独立六店中 A/B 未找到可执行方案，C 找到可执行方案。失败方法成本显示为不可比较，不把名义值当作实际收益。

## 保留验证场景

输入与结果：[holdout](holdout)。

场景 `city-delivery-holdout-010` 有 10 家门店、20 件包装件和 3 辆异构车辆，使用标准 3.0.0 输入，未加入原三场景对照记录。结果：A `SEARCH_EXHAUSTED`，B 与 C `FEASIBLE`，B/C 当前方案费用均为 320.8 元。该结果只说明当前有限搜索边界内的复核结果，不证明大规模能力、全局最优或企业收益。
