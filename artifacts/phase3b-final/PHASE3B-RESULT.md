# Phase 3B 三维主视觉返工结果

## 实际解决的四个问题

1. 04 首屏高度：压缩重复计划信息、隐藏04专用重复版本条、压缩播放条，并让三维舞台使用剩余视口高度。1450×700 首屏现在直接看到车厢和货物，不需要先滚动到下方。
2. 相机异常缩小：旧逻辑按固定长度距离估算。现在由当前车厢长度、宽度、高度和驾驶室包围边界计算相机距离；不同车辆和视角使用同一真实几何边界，不再因步骤更新随意飞远。
3. 冲突不直观：冲突默认进入后门视角，目标与阻挡货物同时留在车内；目标货物使用橙色，阻挡货物使用红色，后门和取货方向可见，blocked 步骤仍停止。
4. 05 与04相似：05现在是“当前装卸作业”主舞台，车厢占主区域；右侧是当前货物、剩余件数和车辆执行状态；辅助路线地图放到主舞台下方。
